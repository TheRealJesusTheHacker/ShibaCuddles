# Security Policy

## Reporting a Vulnerability

Found a security issue in this project? Please report it privately so it can
be fixed before it becomes public.

- Email: **Sentinelsafeguard@outlook.com**
- Include what you found, where (file and line if you have it), and how to
  reproduce it if you can.

Every report is taken seriously and will be acknowledged as fast as possible,
usually within a few days. Please don't open a public issue for a security
problem until there's been a chance to fix it.

## Scope

This policy covers the code in this repository and the binaries published
under Releases.
